# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2025-10-17 [`a01a69f`](https://github.com/paujul/manggaleh-shop/commit/a01a69f)

### Changed

- Start using Vite instead of Create React App
- Migrated from Hasura to Supabase for REST API service
- Rewrite whole app using TypeScript
- Improve Cloudinary image upload
- Fix CSS layout styling from previous version

### Removed

- Everything from v1.0.0

### Added

- `dev-vite` branch
- Main app component layouts (Navbar, Footer)
- Product List main page
- Product Dashboard page
- Create Product form modal

## [1.0.0] - 2022-12-26

### Added

- Released project for capstone scoring
